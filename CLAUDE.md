# Спектр — онлайн-школа

Монорепозиторий: `apps/api` (Fastify + Prisma), `apps/web` (React + Vite + Tailwind v4).
Один фронтенд работает как сайт и как мини-приложение Telegram / VK (`apps/web/src/lib/platform.ts`).
Роли: `ADMIN` (всё + выдача ролей), `TEACHER` («полуадминка»: свои занятия, ученики, ссылки), `STUDENT`.
Запуск: `npm install && npm run setup && npm run dev` из корня. Демо-аккаунты — в README.

## Frontend references
Применяй только когда: создаёшь новую страницу; я говорю, что что-то выглядит плохо;
я называю один из сайтов ниже. Для небольших правок просто выполняй задачу.

- Стиль: DESIGN.md в корне проекта задаёт цвета, типографику и отступы.
  Новый стиль берём с styles.refero.design или из VoltAgent/awesome-design-md.
- Компоненты: сначала 21st.dev (через MCP, если он установлен; перед вызовом
  говори, что ищешь, потому что там лимит), потом component.gallery, чтобы посмотреть,
  как это сделано в зрелых дизайн-системах.
- Анимации: готовый промпт или React-код с kinetics.colorion.co.
- Демо-видео: референсы с whatships.com присылаю я; кадры раскладываются в одно
  изображение (темп, переходы), видео собирается через HyperFrames (hyperframes.dev).
- Финальная полировка: polish и distill из Impeccable (impeccable.style).

Правила:
- Дизайн-система и компоненты проекта всегда в приоритете; внешние референсы
  используются только там, где решение ещё не принято.
- Если нет нужного MCP, навыка или CLI, спроси, ставить ли; не имитируй.
- Если не получается прочитать реальную страницу, остановись и попроси вставить её вручную.
- Всегда называй, какой внешний референс использован и что изменено.
